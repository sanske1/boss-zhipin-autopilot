## 一、红线（一票否决，不看 JD 适配度）

命中任一条直接判否，理由写明命中了哪条。

| # | 红线 | 怎么认 |
|---|---|---|
| 1 | 不投的地域 | 例：只投北上广深 / 不去某几个城市 |
| 2 | 外包、劳务派遣、驻场 | 公司名 + JD 里出现「驻场 / 外派 / 甲方现场 / 人力服务 / 代招」等 |
| 3 | 猎头 / 人才服务 / 第三方代招 | 招聘者署名带「猎头顾问 / 人才服务 / 人力资源」，且公司是第三方 |
| 4 | 明确不投的行业或公司 | 例：竞业公司、特定黑名单 |
| 5 | 非全职 | 实习 / 兼职 / 合同工 |

## 二、读 JD 后的否决项

必须先真实读到 JD 正文才允许用这几条。命中任一条 → 否。

| # | 否决项 | 说明 |
|---|---|---|
| 1 | 学历门槛 | **只有写死的才算**：JD 写「必须 985/211」「一本以下不要」。写「优先」不算门槛 |
| 2 | 必备技能缺失 | JD 把某项技能写成「必备 / 必须 / 要求 / 需具备」，而我完全没有 |
| 3 | 方向或语言栈不符 | 例：主力语言不对（我只写 Python，JD 要求 Go/Java/C++ 为主） |
| 4 | 岗位性质不符 | 例：名为开发，实为数据标注 / 质量评测 / 低代码配置 / 业务赋能 |

## 三、其余按「我能不能胜任」判

- 核心就一条：**JD 里的核心职责，我扛得下来吗？** 扛得下来就投。
- **方向不必完全对口**——相邻方向的开发岗也投，能胜任就行。
- **扣分只认硬门槛**：只认「必备 / 必须 / 要求 / 需具备」。「加分项 / 优先 / 了解 / 熟悉」一律不扣分。
- **年限通常不否决**：1-3 年、3-5 年、5 年以上一般不作为否决项，看技术栈和方向。
- **薪资不单看**：只有「小公司 + 明显低薪」的组合才否决。

## 四、打分怎么给

0–100，≥ 阈值（建议 70）才投。按你关心的事情加权，例如：

1. 技术栈重合度
2. 岗位是否真是这个方向，而非「挂名」
3. 与我简历里最强的项目是否对得上
4. 学历 / 地域 / 语言的硬门槛（只算写死的）
5. 是否 HR 直招（非猎头非外包）
